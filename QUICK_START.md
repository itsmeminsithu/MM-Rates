# Quick start

## Easiest preview on Mac

Double-click:

```text
RUN_DEMO_ON_MAC.command
```

It opens the app with demo rates and does not require npm or SQLite.

## Easiest preview on Windows

Double-click:

```text
RUN_DEMO_ON_WINDOWS.bat
```

## Real server

The demo does not collect data. For the real backend, follow `Web/README.md` and `Web/DEPLOYMENT.md`.

## Mobile projects

- Open `Android/` in Android Studio.
- Open `iOS/MMRates.xcodeproj` in Xcode.
- Run the Web server first or point the native project to a deployed HTTPS URL.
